# License Status for the Public Review Draft

No additional reuse license has been selected for this public review draft. Rights available under applicable law and the hosting service's terms are unaffected. Public availability is not an open-source license.

A future licensing decision remains with the project owner. Options for deliberate review include:

- documentation and templates: `CC BY 4.0`, or `CC0 1.0` if maximum reuse outweighs attribution requirements;
- validation or reference code: `Apache-2.0` or another approved software license; and
- separate rules for the working project name and claims about the framework.

Before granting a reuse license or presenting a stable release:

1. complete the relevant naming and trademark review;
2. decide how modified versions may use the project name;
3. align any chosen license with contributor terms and the Claims Policy; and
4. add appropriate notices and the actual license text after an explicit owner decision.

No license option listed here has been adopted. GitHub's [licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains the distinction between public availability, default copyright rules, and the hosting service's view and fork rights.
